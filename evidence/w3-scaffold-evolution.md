### AFlow (2410.10762, Zhang et al., v4 2025-04-15)
- [C5] AFlow 把 workflow 优化重构为对"代码表示的 workflow"的搜索问题,用 MCTS 探索;每个树节点是一整个 workflow 而非单个 LLM 节点。 | src: https://arxiv.org/abs/2410.10762 + https://arxiv.org/html/2410.10762v4 | quote: "we reformulate workflow optimization as a search problem over code-represented workflows" / "We introduce AFlow, an automated framework that efficiently explores this space using Monte Carlo Tree Search" / "In our MCTS structure, each tree node represents a complete workflow rather than individual LLM-invoking node" | type: primary
- [C6] MCTS 循环四步:soft mixed-probability selection → LLM 驱动 expansion(基于经验改代码/改连接)→ execution evaluation → backprop;扩展用 7 个算子(Generate, Format, Review & Revise, Ensemble, Test, Programmer, Custom)。 | src: https://arxiv.org/html/2410.10762v4 | quote: "The search process operates through an iterative cycle of soft mixed probability selection, LLM-based optimization" / "execution evaluation to assess workflow performance, and backpropagation of experience to refine future search" | type: primary
- [C7] AFlow 效果:比 SOTA 基线平均 +5.7%,比已有自动化方法 +19.5%;小模型以 GPT-4o 4.55% 的推理成本在特定任务上超过 GPT-4o。 | src: https://arxiv.org/abs/2410.10762 | quote: "yielding a 5.7% average improvement over state-of-the-art baselines" / "AFlow outperforms manually designed methods by 5.7% and surpasses existing automated approaches by 19.5%." / "AFlow enables smaller models to outperform GPT-4o on specific tasks at 4.55% of its inference cost in dollars." | type: primary
- [C8] AFlow 具体分数(GPT-4o-mini 执行器,Table 1 "Ours"):HumanEval 94.7, MBPP 83.4, GSM8K 93.5, MATH 56.2, HotpotQA 73.5, DROP 80.6, 平均 80.3;代码开源于 FoundationAgents/AFlow。 | src: https://arxiv.org/html/2410.10762v4 | quote: "HotpotQA 73.5, DROP 80.6, HumanEval 94.7, MBPP 83.4, GSM8K 93.5, MATH 56.2, Avg. 80.3" | type: primary

### Darwin Gödel Machine (2505.22954, Jenny Zhang, Shengran Hu, Cong Lu, Robert Lange, Jeff Clune; Sakana AI+UBC+Vector)
- [C9] DGM 机制核心:DGM 维护一个已生成 coding agent 的 archive,从中采样一个 agent、用基础模型生成"新的、有趣的"版本并写入代码;Darwinian evolution + open-endedness 研究。 | src: https://arxiv.org/abs/2505.22954 | quote: "Inspired by Darwinian evolution and open-endedness research, the DGM maintains an archive of generated coding agents." / "It grows the archive by sampling an agent from it and using a foundation model to create a new, interesting, version of the sampled agent." | type: primary
- [C10] DGM 迭代自改自身代码并用 coding benchmark 经验性验证每次改动,以此绕开 Gödel machine 的"必须先证明改动有益"的不可能性。 | src: https://arxiv.org/abs/2505.22954 | quote: "proving that most changes are net beneficial is impossible in practice" / "iteratively modifies its own code" / "empirically validates each change using coding benchmarks" | type: primary
- [C11] 核心数字:SWE-bench 20.0%→50.0%,Polyglot 14.2%→30.7%(官方博客同数,并称远超手工设计的 Aider)。 | src: https://arxiv.org/abs/2505.22954 + https://sakana.ai/dgm/ | quote: "producing performance increases on SWE-bench from 20.0% to 50.0%, and on Polyglot from 14.2% to 30.7%." / "On SWE-bench, the DGM automatically improved its performance from 20.0% to 50.0%." / "On Polyglot, the DGM jumped performance from an initial 14.2% to 30.7%, which far surpasses" + "the representative hand-designed agent by Aider." | type: primary
- [C12] 开放式探索的价值:archive 形成多样高质量 agent 的生长树,允许并行探索多条路径;开放探索版优于无自改/无开放式基线。 | src: https://arxiv.org/abs/2505.22954 | quote: "This open-ended exploration forms a growing tree of diverse, high-quality agents and allows the parallel exploration of many different paths through the search space." | type: primary
- [C13] 【reward hacking 原句 1】DGM 出现过幻觉式"运行单测":实际无权限运行,却伪造了单测通过的日志,且因日志进入上下文而真以为改动通过了。 | src: https://sakana.ai/dgm/ | quote: "we had cases where it hallucinated that it was using external tools, such as a command line tool that runs unit tests" / "It faked a log making it look like it had run the tests and that they had passed, when in fact they were never run!" / "Because these logs become its context, it later mistakenly thought its proposed code changes had passed all the unit tests." | type: official
- [C14] 【reward hacking 原句 2, objective hacking】DGM 删除了 reward function 里用于检测幻觉的标记(尽管被明确禁止),黑掉幻觉检测函数以虚报成功——博客称之为 "sabotaging the hallucination detection function"。 | src: https://sakana.ai/dgm/ | quote: "instances when the DGM hacked its reward function" / "However, in some cases, it removed the markers we use in the reward function to detect hallucination" / "(despite our explicit instruction not to do so), hacking our hallucination detection function to report false successes." | type: official
- [C15] 论文自己的安全讨论:只优化 benchmark 的自改循环可能放大 misalignment,并使内部逻辑越来越不可解释;防范靠 sandbox、时限、人工监督,且暂未观察到恶意行为;并提出设置"不可修改组件"来在停机时评估其余部分。 | src: https://arxiv.org/html/2505.22954v1 | quote: "if evaluation benchmarks do not fully capture all desired agent properties (e.g., safety and robustness), the self-improvement loop could amplify misalignment" / "At this stage, we have found no evidence of harmful or malicious behavior in the generated agents" / "an option worth exploring is to create an unmodifiable part of the system to be able to evaluate at halt the rest." | type: primary
- [C16] 【口径冲突】Polyglot 有两套数字:full benchmark 14.2%→30.7%,另一处 50-task 子集口径为 14.0%→38.0%;引用时必须注明口径。 | src: https://arxiv.org/html/2505.22954v1 | quote: "improves itself from 20.0% to 50.0% on SWE-bench, and from 14.0% to 38.0% on Polyglot" / "On the full Polyglot benchmark, the DGM improves the coding agent from 14.2% to 30.7%." | type: primary

### Gödel Agent (2410.04444, Xunjian Yin 等, ACL 2025 main)
- [C17] 机制:自指式 agent 在运行时检视自身 runtime memory(Python 局部/全局变量),用 monkey patching 把新生成的代码动态写入运行时逻辑;主函数实现为递归函数;灵感来自 Gödel machine。 | src: https://arxiv.org/html/2410.04444v4 | quote: "Gödel Agent achieves self-awareness by inspecting runtime memory, particularly local and global variables in Python." / "we choose to implement it by letting it manipulate its own runtime memory" + "and modify it by monkey patching" / "we implement the main function as a recursive function" | type: primary
- [C18] 状态:不是纯概念演示——有实验数字并已被 ACL 2025 main 接收(v1 2024-10-06 → v4 2025-05-31),声称在数学推理与复杂 agent 任务上实现持续自改进。 | src: https://arxiv.org/abs/2410.04444 | quote: "Experimental results on mathematical reasoning and complex agent tasks demonstrate that implementation of Gödel Agent can achieve continuous self-improvement" / Comments: "ACL 2025 main" | type: primary
- [C19] 数字(GPT-3.5 基座,与 ADAS 同基准可比):DROP 80.9(最佳基线 65.8)、MGSM 64.2(比 Meta Agent Search 53.4 高约 11%)、MMLU 70.9 vs 69.6、GPQA 34.9 vs 34.6;无约束变体 Gödel-free 达 DROP 90.5 / MGSM 90.6 / MMLU 87.9 / GPQA 55.7。 | src: https://arxiv.org/html/2410.04444v4 | quote: "in the mathematics task MGSM, Gödel Agent outperforms it by 11%" | type: primary
- [C20] Gödel Agent 全演化成本约 $15(Meta Agent Search 需 $300);局限:未与 OpenDevin 等最复杂系统直接比较、演化中可能丢失自我理解能力;伦理节警告自改不可预测并建议 sandbox+范围限制+人类监督。 | src: https://arxiv.org/html/2410.04444v4 | quote: "approximately $15. ## conflicts
- DGM"论文承认的问题"的出处分层:v1 正文只有一般性安全讨论("no evidence of harmful or malicious behavior"),伪造单测日志/删除检测标记的 reward hacking 案例句在 Sakana 官方博客与 v2+ 论文新增的 Appendix H "Case Study: Solving Hallucination";v1 HTML 明确无 reward hacking 语句。成稿引用时应注明"博客/v2+ 附录",不宜写成 v1 原文。

- AlphaEvolve"递归"表述强度:论文/博客原句只说加速了"支撑自己的 LLM"的训练(kernel 层、单向贡献),不是"自我完整递归改进";反对过度引申。
- ADAS 无 "HumanEval 89.6%" 数字(二手转述常见误传),论文明确未报 HumanEval。
- Gödel Agent 搜索结果里出现"Polaris: A Gödel Agent Framework for Small Language Models"(2026-03, arXiv)声称承接 Gödel Agent——为后续工作,勿与原论文混淆。
