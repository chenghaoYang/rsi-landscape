# RSI(Recursive Self-Improvement,递归自我改进)调研 Brief

任务:完整调研 2026 年 AI 领域的 RSI(Recursive Self-Improvement,递归自我改进)概念,重点是它对 AI agent 的具体细节——从简单到复杂的层次演变、每一层的具体做法。

读者:工程师 / AI 从业者。懂 agent 开发(LLM、prompt、工具调用、微调),不需要 AI 基础科普。

三疑点(用户点名):
1. RSI 从简单到复杂分几层?每层是什么?
2. 每一层对 AI agent 的具体做法/机制是什么?要有系统、参数、流程,不要空谈概念。
3. 哪些已实现、有实证(benchmark/生产证据)?哪些还是概念、畅想或民间叙事?

范围:
- 内:RSI 定义与谱系(Good 1965 → Gödel machine → AIGA → 2025-2026 agent 系统)、分层框架(找多种主流分法并对照)、每层代表系统与机制细节、实证与负面证据、安全与评估、政策阈值、2025-2026 最新动态。
- 外:金融技术指标的 RSI(Relative Strength Index);无关的通用强化学习教科书内容。

完成标准:report.md(≤20000 字符)独立回答三疑点;atlas.md 字段级对照册;details/ 细节页;关键主张可溯源;⚔ 冲突有裁决;终审回原页核验。
